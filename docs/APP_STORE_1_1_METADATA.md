# Couple Flight Chess 1.1 App Store Metadata

Use this copy for the US English localization in App Store Connect.

## Search Metadata

- App name: `Couple Flight Chess`
- Subtitle: `Romantic truth or dare for two`
- Primary category: `Games`
- Games subcategory: `Board`
- Secondary category: `Lifestyle`
- Keywords (90 bytes):

```text
date night,relationship,love,partner,intimate,flirty,ludo,dice,challenge,party,adult,spicy
```

The keywords intentionally avoid repeating words already present in the app name,
subtitle, or category. Do not add `sexy`; explicit search terms can be filtered and
may create unnecessary metadata review risk.

Turn date night into a playful board game with romantic challenges, private room

Improved private-room guidance, smoother gameplay, and a better end-of-game

## App Store Tags

In `Distribution > App Information > App Store Tags`, keep only tags that
accurately describe the app. Prefer relevant US tags related to board games,
couples, date night, party games, and truth or dare when Apple offers them.

## Availability

The current release is available only in the United States. Search testing must
use an Apple Account whose App Store country or region is set to the United
States.
