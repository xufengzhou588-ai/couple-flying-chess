# 下一款情侣小游戏：双指心动（产品草案）

状态：**设计草案，尚未进入 TestFlight 构建 12**。目标是增加两人同时动手玩的情趣，不再增加一款以读卡为主的游戏。与现有“午夜调情”视觉、三语和音效系统保持一致。

## 玩法核心：两人一部手机

1. 两人面对面，每人把一根手指按在屏幕两侧各自的光点上。屏幕显示两条交汇的弧线与中间的心形。
2. 两人一起缓慢滑动。手指移动时两道光轨跟随、心跳与音乐节拍增强；只有两人都在滑动，心形才逐渐亮起。节奏不同不会“输”，屏幕只提示“慢一点，等我一下”。
3. 两道光轨在心形相遇，揭开一个双方预先选过尺度的小互动，例如看着对方说一句具体的赞美、手指轻碰、或在对方耳边说一句想对方再靠近一点的话。两人都能点“换一个”或“跳过”。
4. 一局三轮，每轮换一种轨迹：靠近、绕圈、同步画心。完成后可以选择“再玩一轮”，不计分、不排名。

屏幕上使用 `Pointer Events` 区分两个触点；只在游戏区域阻止浏览器滚动。玩家可随时松手暂停，再按回原来的起点继续。兼容性不足时提供双人轮流滑动，绝不让游戏卡死。动效用光轨、心形、轻微音效表达亲密感；不要把手机震动写成 iPhone 上一定可用的功能。

### 开始前的共同选择

- 两人分别私密选 `Sweet`、`Teasing`、`Bold` 的接受范围；只出现双方都愿意的环节。
- `Bold` 默认关闭，进入前说明更直接的调情内容，任何时候可以退出、换题或跳过。
- 不记录触摸轨迹、偏好、语音，也不把私人选择上传。首版只支持同一部手机；远程同步需要独立设计与测试。

## 悄悄话配对作为可选环节

不要再做一整套纯文字问答。每人先各自滑动卡片，选喜欢的**说话风格**：具体赞美、轻轻挑逗、期待下一次约会、略直接的暗示。仅展示双方都选了 `Yes` 的风格；`Maybe` 用于“先聊聊”，`Pass` 和未配对选项不公开。

双指心动完成后，若双方同意，解锁一句短的开场提示，由一方对另一方**亲口说**，另一方可滑动选“更大胆 / 温柔一点 / 换一句 / 到此为止”。提示应该帮助两人自己说出有个人感的句子，而非朗读生硬模板。默认不录音、不存聊天记录。

## 与现有产品的区别及上线次序

- Chemistry Dice 是随机动作与部位；双指心动的核心是**两人同时控制同一画面**，产生实时配合与靠近感。
- The Slow Burn 已有私密选择和角色场景；悄悄话环节应以**声音说出口、对方实时调节尺度**为核心，不再复制“选卡然后看结果”的结构。
- 先让用户在 TestFlight 验证 1.1.1 构建 12 的骰子修复与摇动。双指心动适合下一次独立 TestFlight 构建，届时再更新目录、截图、商店描述和三语语音。

## 参考与验证

美区 App Store 的 [Thumbkiss](https://apps.apple.com/us/app/thumbkiss-couples-app/id6754659424) 使用双人触摸与反馈；[Foreplay](https://apps.apple.com/us/app/foreplay-couples-date-night/id6739634971) 展示了骰子、绘画与尺度选择；[Xplore](https://apps.apple.com/us/app/xplore-couples-intimacy-quiz/id6744415156) 将 dirty talk 列为私密兴趣匹配分类。这些产品页证明玩法在市场中存在，不能证明目标用户普遍偏好。下一步用少量美区 TestFlight 用户观察：是否能在 10 秒内理解双指操作、是否真正同时玩、是否愿意说出解锁的那一句，以及哪些提示让人尴尬或想跳过。
